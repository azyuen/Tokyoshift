# Garage art slots

R10 makes the workshop screen asset-driven.

Current placeholder assets:
- `workshop_bg.svg` — full workshop background. Recommended replacement canvas: 1200 × 520 or the same aspect ratio.
- `character_left.svg` — standing static character sprite.
- `character_right.svg` — crouching/static mechanic sprite.

The file paths are defined in `src/data/garageAssets.js`. When final PNG artwork is uploaded, update the paths there and the scene layout can stay unchanged.
