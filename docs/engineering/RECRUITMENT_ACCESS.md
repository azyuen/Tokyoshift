The Plaza route opens with the same seven championships as recruitment and does not require a recruited crew. Each successful three-round event nets ¥675,000 on Standard/Hard; it costs ¥75,000 to enter and has a 15-minute venue cooldown. Figures retain an entry-fee reserve. These are conditional savings counts, not proof that a given player/build can win Elite showdowns. Lower-stakes repeatable meets are another income route but buying a car solely from those wagers can require extensive grinding.

Decision: no immediate dealership or reward-price changes. There is no class availability or crew-unlock dependency loop in this branch, but affordable access is not guaranteed for a depleted save. Before release, playtest a spent-down seven-championship profile and reconcile current main’s recruitment invitation changes. A failed or deferred invitation must remain retryable.
